How to create a PAT? 1. Go to GitHub Settings → Developer settings → Personal access tokens → Fine-grained tokens
2. Click "Generate new token"
3. Set "Repository access" to "Only select repositories" → choose your notes repo
4. Under "Permissions" → "Contents" → set to "Read and write"
5. Generate and copy the token, then paste it above
